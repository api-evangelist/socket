There's a new package manager in town, and this one fits in about 250 KB. Pooya Parsa , a longtime Nuxt contributor and creator of Nitro and UnJS, has introduced upm , a TypeScript package manager for the npm registry that uses Node.js's built-in networking, worker threads, compression, and filesystem tools. It has a JavaScript API, reads supported .npmrc settings, and can install from several other package managers' lockfiles.
